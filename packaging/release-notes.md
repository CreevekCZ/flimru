First release of Flimru, a terminal launcher for Flutter projects.

- Pick a device and a VS Code launch configuration, with support for project FVM SDKs.
- Run up to eight sessions with independent consoles, hot reload, and searchable logs.
- Let a local agent start, inspect, and control the same runs over MCP or the CLI.

The binary is for Apple Silicon Macs. Use the [Homebrew or agent setup instructions](https://github.com/CreevekCZ/flimru/blob/main/README.md#install).
For manual downloads, verify the archive with `SHA256SUMS`. MIT licensed.
